# A02–A04 / A11 · Local card and safe exchange
A02 本地普通/敏感数据隔离、口令 vault、会话锁定、加密备份/原子恢复；基础名片不强制口令。
A03 无注册最小输入，可变 5:3 模块、三种动效、键盘/reduced-motion 和 360/390/768/1440。
A04 确认后白名单新对象、文件/图片/vCard，移除 EXIF，拒绝 SVG，测试未选字段在字节/图像/元数据不出现。
A11 接收者无注册保存/回赠，离线只缓存本地已准备数据/静态资源，不缓存公共敏感接收页；系统分享取消和不支持要降级。
公开托管和撤下不混入本任务，见 A10。不得假装 WebView 能访问另一个浏览器的 vault。
