# A05 / A10 · Cloud boundary and explicit publication
A05 匿名 session owner、CSRF、内容散列批准、配额/预算、24h 提案清理、无正文日志。免注册不是开放他人任务读取。
A10 只接受已确认的 ShareProjection，公开随机链接、独立本地撤下凭证、幂等/不可变快照、30d 默认到期。新发布需明确确认；默认通用 OG。公开链接可转发，不含私有标签/策略，不宣称 E2EE。
云端 AI 与 publication store 隔离；用户明确选择发布的联系方式可以出现在快照，但绝不能因此输入 AI。供应商留存、托管、备份清理和实际部署需单独核验。
