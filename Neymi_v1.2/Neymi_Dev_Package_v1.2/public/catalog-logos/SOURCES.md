# Catalog logo sources

- The homepage card example uses the official NVIDIA vertical logo from the [NVIDIA Newsroom media assets](https://nvidianews.nvidia.com/multimedia/corporate/nvidia-logos). NVIDIA marks remain NVIDIA trademarks; the card is clearly presented as sample content.

These image files are bundled locally so picker and card views do not depend on third-party image hosts.

- Social brand icons: [Simple Icons](https://github.com/simple-icons/simple-icons), SVG assets, CC0 1.0; license text is in simple-icons-LICENSE.md. LinkedIn is from [SuperTinyIcons](https://github.com/edent/SuperTinyIcons), SVG asset under MIT; license text is in super-tiny-icons-LICENSE.txt. Douyin uses the current logo SVG served by its [official CDN](https://lf3-static.bytednsdoc.com/obj/eden-cn/ulkphgeh7nuvspognuhbo/douyin_web/img/images/logo-horizontal.svg).
- Credential issuer marks: actual website favicons fetched for each issuer domain from Google's public [favicon service](https://www.google.com/s2/favicons). Cisco uses Simple Icons (CC0). Microsoft uses the official four-square brand shape from [Font Awesome Free](https://github.com/FortAwesome/Font-Awesome), CC BY 4.0; its SVG includes attribution. SHRM and HRCI use current SVGs from the [SHRM official site](https://www.shrm.org/content/dam/en/shrm/brand-logos/shrm-main.svg) and [HRCI official site](https://www.hrci.org/images/default-source/public-content/desktop/sitewide/hrci-logos/hrci_logo_nospace_purple.svg?sfvrsn=cbdcdd46_0).
- University marks: [universities-domains-list](https://github.com/benwhalley/universities-domains-list), files from the logos directory matched by institution domain/name. The repository collection is MIT-licensed; institutions retain rights in their marks.

Credential icon filenames map to issuer domains: pmi.org, cfainstitute.org, aicpa-cima.com, accaglobal.com, garp.org, cfp.net, isaca.org, isc2.org, comptia.org, cisco.com, aws.amazon.com, microsoft.com, cloud.google.com, google.com, scrumalliance.org, scrum.org, peoplecert.org, ielts.org, and ets.org. The credential title is always retained beside its issuer mark.

## Gaps

- Science Tokyo is not represented by a current asset in the university source. Its [official brand page](https://www.isct.ac.jp/en/001/about/brand/logo) warns against unauthorized logo use; no predecessor Tokyo Tech mark is substituted.
- Columbia University’s shield file was present in the source manifest but the repository file endpoint returned no content; no substitute is shown.
- “Other” and custom social entries intentionally have no logo.
- Credential icons identify their issuer; they are not certification badges or proof of certification. Generic Six Sigma has no single issuer, so it remains text-only rather than showing an unrelated mark.

Logos are identifying marks, not proof of enrollment, employment, or certification. Users control what they add to and share from a card.
