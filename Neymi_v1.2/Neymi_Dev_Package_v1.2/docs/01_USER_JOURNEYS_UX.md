# UX v1.3 — 先用名片，再为具体的人准备
2026-10-25。以下是 v1.3 UX 基线；实现与验证状态记录在 `docs/verification/` 和 `docs/06_DELIVERY_BACKLOG.md`。

2026-10-26 B 阶段补充：创建者页 `/`、`/prepare`、`/activity`、`/cards` 使用共享助手浮窗；会话只在当前页面应用内存中存活，刷新清空。单人对话只提交本轮用户文字和显式勾选的本人事实；活动页复用现有逐人身份确认与上下文审批。策略/草稿进度摘要追加回同一助手会话。入口打开不触发云请求；服务未配置或失败时仍可手工准备。执行证据见 `docs/verification/card-and-assistant-2026-10-26.md`。

## J-A01 免费快速使用
输入展示名称即可进入基础预览，其余可选；无需账户、口令、AI 对话、电话或付费。提供松林、素纸、海岸、陶土、夜航、紫藤六款免费模板，点击即可预览和切换，并在此浏览器记住模板选择。模板不要求注册；所选模板跟随本地预览、分享投影、公开卡片和 PNG 导出。可编辑模块，导出或明确发布后分享。完成首次预览/使用后轻量提示“让 AI 帮你为不同的人准备介绍”，不阻断当前任务。回赠复用同一基础流程。

## J-A02 AI 了解本人
首次开启云端对话说明处理范围，提醒不要输入电话/邮件/地址等。先询问目标和已有材料，逐步补充，不固定长问卷。发送前本地识别疑似敏感项并建议替换；用户可查看实际发送内容。AI 提取候选事实，用户确认/编辑后本地保存；未经确认的数字和成就不成为事实。
复用资料时展示拟发的最小职业摘要，不自动上传历史或完整 profile。邮箱、电话、微信、WhatsApp 等敏感联系方式始终在独立本地表单；选择持久保存才创建加密保险库/解锁口令，并提供备份提示。解锁不是注册。

## J-A03 单人背景
输入接收人的嘉宾介绍、公开链接或文字说明，以及场景/交流目的。A 不要求活动、不解析 PDF。状态 submitted/researching/needs_confirmation/ready/partial/failed/cancelled；身份有歧义先确认。用户陈述与公开验证信息区分；展示来源、日期、未知和冲突。无法访问时粘贴材料、跳过或采用有限背景方案。

## J-A04 方案
展示本次表达重点、选用的本人材料、理由和接收人依据，以及推荐开场/下一步、风险与未知。用户修改、拒绝、补充均可；不得先自动生成大量名片。接收人不适合当前目的时解释原因，不编造共同点，也不阻止用户手动做基础名片。

## J-A05 批准与本地合成
授权界面显示字段/嵌套项、用途、当前设备、recipe、有效时间（5/15/60 分钟，默认 15）。默认不选电话、邮件、地址、照片。界面区分云端处理、本地合成和最终分享。
本地校验授权后预览；过期/撤销拒绝新读取，已生成草稿不自动消失，已传云端内容不能靠授权过期收回。没有本地资料时提示在原浏览器打开或导入加密备份。

## J-A06 方案库与分享
按接收人、场景和名称检索；标签默认私有，公开称呼/寄语明确选择。显示 draft/ready/stale/archived；分享记录属于独立发布记录，不混用 recipe 状态。资料变化标记 stale，已发布快照不自动更新。
最终预览显示全部实际分享字段；可删除任一字段。文件/图片/vCard 为本地生成；vCard 明示明文。公开链接必须明确发布所选内容，提示可转发。通用 OG 默认，研究策略和私有标签不进入卡片。已发布链接可撤下，但不承诺删除收件人副本/缓存。
接收页无需登录，展开详情、保存、回赠；不显示研究策略，不强迫回赠。

## 异常和降级
| 场景 | 行为 |
|---|---|
| 云端不可用/无配置 | 明确不可用，基础名片及缓存方案仍可使用；演示结果明确标注 |
| 本地空间不足/事务失败 | 保留当前编辑，提示导出，不声称保存成功 |
| 口令遗失 | 如实告知无服务器找回；可恢复可解锁备份或重新建立资料 |
| 错浏览器/跨设备 | 不假装已同步；提供原浏览器/备份导入路径 |
| 相同姓名/矛盾机构 | 请求用户确认身份，确认前不生成确定性针对建议 |
| 网页登录墙/来源不足 | 说明受限，不绕过；可手动补充 |
| 系统分享不支持/用户取消 | 下载/复制降级；取消不计作成功分享 |
| 离线 | 本地预览与导出可用；新研究、首次发布明确需要联网 |
| 发布中断/重试 | 幂等处理，不生成一堆重复公开副本 |
| 原资料编辑/删除 | 关联方案 stale；公开快照仍需用户另外撤下 |

## 视觉与可访问性
继承 5:3、可变模块、可选头像/logo、详情展开、三种动效；六款免费卡片皮肤不限制内容模块布局，不强制六宫格。360/390/768/1440 检查无横向溢出，键盘焦点恢复、触摸目标、对比度、reduced-motion。首版不为高级卡套阻挡内容。

## B/C 延伸
B：活动/文件 → 至多 20 人 → 确认身份 → 筛选 → 逐个或批量批准方案。C：官方聊天入口 → 安全短期 deep link → 原设备本地批准；聊天同意不是设备授权。
