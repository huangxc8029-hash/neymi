# A07 — 单人公开研究与身份确认

2026-10-25。新增 SSRF 安全的公开页面抓取、单接收人研究 API 与准备页面板。抓取只接受 HTTPS/443；校验全部 DNS 地址并固定连接到已验证 IP；拒绝私网/保留地址、混合公私 DNS、跳转、非文本内容和非 identity 压缩；每响应最多 2 MiB、5 秒，正文剥除脚本/样式后最多 20,000 字符。

来源片段保持 unknown，不被提升为事实。接收人身份初始为 unverified，用户确认后才变为 verified。任务按匿名会话隔离，取消阻止延迟结果覆盖，24 小时后删除，单会话 5 分钟内最多 10 次请求和 10 个来源。任务仅在进程内存，不写入 SQLite；重启会丢失任务。来源内容按不可信文本处理，不执行其中指令。

修复 Zod URL 协议格式，确保 HTTPS URL 通过契约校验。RED：目标集成测试对缺失模块失败。GREEN：研究专项 8/8、全套 93/93、类型检查、lint、生产构建通过。生产构建需要工作区文件系统访问，因为默认沙箱阻止 Next.js worker 写 `.next` 内部目录。

外部门槛：未配置公开搜索 provider，真实姓名检索不会伪装成功，任务会显示服务未配置。测试使用受控 DNS 与传输，不执行真实互联网抓取；浏览器 E2E 因 Playwright 浏览器安装索引缺失未运行。
