# A11 — 接收、回赠与离线降级

2026-10-25。公开卡片提供“保存到此浏览器”和“回赠我的名片”；Neymi `.ncard` 文件只接受严格 `ShareProjection` JSON，不执行 HTML/SVG。收到的卡片存入单独的 IndexedDB 键，不修改本人 profile。分享预览与接收页均提供系统分享，支持 Web Share 文件能力，取消返回 `cancelled`，不支持或出错时下载 `.ncard`。

离线服务工作线程仅缓存无用户数据的应用页面壳、manifest 与静态 Next 资源。`/p/*` 和 `/v1/publications/*` 始终直连网络，不写 Cache API；离线公开链接显示明确提示。需要离线访问的准备卡必须由用户单独请求，写进 AES-GCM vault；资料版本变化后旧副本不再显示。收到的公开卡片可在本地浏览器保存，不进入本人资料。

RED：接收模块缺失时测试按预期失败。GREEN：导入 schema/分离存储、AES 加密缓存/锁定拒绝/修订失效、缓存策略、无 Web Share API 回退专项 4/4 通过；完整 Chromium E2E 14/14 通过（本地浏览器旅程使用明确标记的研究/方案 fixture）。另有真实 Service Worker 断网测试通过：公开页面转离线提示、公开页面/API 都未缓存；主 E2E 因共享浏览器上下文稳定性配置而屏蔽 Worker。typecheck 和 lint 通过。系统分享取消路径未在真实聊天应用验证。

限制：被接收的公开名片本身以明文存入此浏览器 IndexedDB，因为内容已由发送者公开；删除只影响本设备。离线加密副本由当前 vault 口令保护，且不包含在 profile backup 中，需重新生成/缓存。
