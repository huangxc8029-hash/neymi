# A10 — 公开快照、撤下与到期

2026-10-25。只接受 A04 的 `ShareProjection` 与 `publish` 内容摘要确认。匿名会话拥有者与幂等键绑定快照；同一键/同一内容重试返回原链接和撤回令牌，同一键/不同内容拒绝。服务生成随机 publicId，撤回令牌由独立稳定服务密钥导出，数据库仅存 SHA-256 摘要；快照默认 30 天。撤下后立即不可读取；到期任务删除投影正文并保留无正文墓碑，公开 API 明确返回到期状态。公开页面动态渲染且 API 设置 `Cache-Control: no-store`，不输出接收人标签/Recipient ID。

红绿验证：先写服务测试，模块缺失时按预期失败；之后幂等、摘要不匹配、错误撤回令牌、到期清除、跨 owner 隔离、撤回令牌哈希、SQLite 跨实例持久化 4/4 通过。A12 最终验收：全套 Vitest 110/110，typecheck、lint、production build 通过；Chromium E2E 14/14 通过。

部署依赖：设置至少 32 字节的 `NEYMI_PUBLICATION_SECRET` 和 `NEYMI_SESSION_SECRET`，将 `NEYMI_SQLITE_PATH` 指向持久卷，并用独立 `NEYMI_CLEANUP_SECRET` 配置平台定时任务 POST `/v1/maintenance/cleanup`。本地代码提供清理入口，但没有配置实际托管平台 cron、TLS、域名、备份策略或真实发布服务；A12 必须据实标记。
