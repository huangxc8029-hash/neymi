# A04 — 白名单分享与导出

2026-10-24。每次分享先勾选展示字段，再生成全新 `ShareProjection` 供最终核对。投影只含所选身份、模块字段、资源和公开寄语；私有接收人标签、策略、内部 ID 不进入文件。分享确认绑定投影 SHA-256 摘要和具体动作；改动后需要重新预览。

名片 JSON、vCard、PNG 图片只消费投影。vCard 对换行、反斜线、分号和逗号转义。媒体输入限制 PNG/JPEG/WebP 和 5 MiB，浏览器解码再编码为 PNG；进入公开投影时只接受 PNG，并剔除辅助元数据块。SVG 与内容伪装会拒绝。

RED：投影和导出函数未实现时，目标测试 3 项失败；原始 JPEG 可进入快照的负例随后先失败再修复。GREEN：分享单元测试 8/8；浏览器确认下载名片、PNG、vCard 测试通过，未勾选内容没有进入文件。

限制：媒体的浏览器重编码还需在目标手机和目标聊天浏览器验证；通用 PNG 解析不等同于独立媒体安全审计。分享后他人保存的副本无法撤回。
