# A02 — 本地敏感保险库

2026-10-24。普通字段可免口令保存在本地；敏感字段及图片以 AES-256-GCM 加密。口令经 PBKDF2-SHA256、16 字节随机 salt、310000 次迭代导出不可导出的会话密钥。每次加密使用 12 字节随机 nonce；密钥仅在内存，15 分钟闲置锁定，页面重载自动回到锁定状态。

存储适配器提供 IndexedDB 与内存测试版本；普通资料和密文是独立记录。加密备份包含版本/盐/参数，导入先验证和解密，再以单次事务替换。事务或口令验证失败不覆盖旧库。

验证：目标测试先观察 6 项未实现失败；增加锁定更新与错误分类负例，均先观察失败再修复。最后 vault 11/11、全量单元 59/59、类型检查和本任务静态检查通过。涵盖重载锁定、空间不足不覆盖、旧版备份拒绝与篡改恢复。

限制：310000 次参数尚未在目标手机上测量；密码学实现尚未经独立审计。忘记口令无法由服务器找回。设备浏览器清理存储后需使用加密备份恢复。
