# A05 — 匿名 API 与云端数据边界

2026-10-25。实现同源 API 路由、24 小时匿名会话、HMAC 签名的 HttpOnly/SameSite cookie、写请求 Origin 检查、批准上下文内容散列验证、每会话每小时 10 个任务、按 owner 隔离、主动删除和 24 小时到期清理函数。未知 job 内容与跨 owner 读取都拒绝；错误响应不包含请求正文。

存储适配含内存测试实现和 SQLite 持久实现，SQLite 重启后数据及所有权校验通过。每请求最多 20,000 字符由上下文 schema 约束。未配置会话密钥或持久 SQLite 路径时云端写接口明确不可用。LLM provider 当前显式返回 SERVICE_UNAVAILABLE，没有伪造模型结果。

RED：5 项目标测试对缺失实现失败。GREEN：11 项集成测试通过，覆盖签名/过期会话、跨源写保护、所有权、清理、配额、上下文摘要、SQLite 重启持久性与主动删除；类型检查和 lint 通过。
