# Neymi 紫白设计系统与整站 UI 执行方案

状态：待实施方案。本文件只定义后续工作，不表示功能已实现。目标执行者：GPT-6 Luna。日期：2026-10-27。

配套文件：`2026-10-27-ai-card-designer-plan.md`、`2026-10-27-card-designer-skill-draft.md`。先执行本文件 U0–U3，再按两个方案的依赖顺序继续。代码根目录是本文件所在仓库根，不是外层资料目录。

## 1. 已确定的设计决策

采用用户选中的“Soft Signal 柔紫助手”效果图：白色编辑区、淡紫预览区、深紫主要按钮、深灰文字、现代无衬线字体。视觉参考是图片中的色彩、左右结构和留白；图片里的未实现能力必须按配套功能方案开发，不能做假按钮。

产品是名片制作工具。进入首页即能编辑，不再先滚过大宣传标题和整块示例卡。名片本体是画面焦点；装饰面积让位于表单和预览。AI 是可选的创作入口，手动制作始终可用。

必须保留已确认需求：
- 五个步骤：01 基础信息、02 联系方式、03 其他个人信息、04 挑选模板、05 选择显示内容。
- 基础信息含企业/团队 Logo 上传；个人信息步骤有“跳过”。
- Others 为名称与内容两个输入；卡面只显示名称，点击查看内容；名称无矩形边框。
- 社交字段为“账号名称”，不自动转成网址；个人网站独立进行 URL 校验。
- Free、VIP 模板在步骤 04 同屏，每组初始仅三张，More 打开选择器；不恢复多余预览按钮。
- “打开效果”放步骤 04 右上角，紧凑显示。
- 步骤 05 是一个字段列表，VIP 项尾部标记 VIP，不做 Free/VIP 两个 tab，保留“跳过”。
- 完成并分享只出现“分享名片 / 复制链接 / 下载名片”三个按钮，没有第六个 tab。
- `/vip` 已删除，不重建页面或入口。历史 VIP 卡仍正常显示。

标题下说明统一为“填写、挑选、分享，让名片更像你。”这替代旧“简单3步”文案，避免与五个实际步骤冲突。页面不额外堆叠营销标语。

## 2. 当前实现与改造边界

已核对：入口 `src/app/page.tsx`；编辑器 `src/modules/card/editor.tsx`；渲染器 `renderer.tsx`、`card-experience.tsx`；模板 `templates.ts`、`template-picker.tsx`；公开字段 `visibility-panel.tsx`；分享 `src/modules/publication/quick-share.tsx`。全局 `src/app/layout.tsx` 目前直接导入大块样式和 AssistantProvider。

当前 `styles.css` 包含多轮覆盖、旧深色和绿色规则。不能在文件末尾无限追加全局覆盖。建立带作用域的新组件样式，逐页迁移；只有确认无引用的旧规则才移除。不能全局改 `button/input/h1` 后让卡片主题跟着变色。

产品界面与卡片主题是两个系统：紫白只用于站点外壳、编辑器和操作控件；用户选中的名片模板继续使用其自己的色彩。公开页外围使用中性浅色，名片按选定模板呈现。

## 3. 可直接实施的设计变量

新增 `src/styles/tokens.css`，以 `--ui-*` 命名，避免与 `--template-*` 冲突。

| Token | 值 | 用途 |
|---|---|---|
| --ui-bg | #FAF9FD | 全站底色 |
| --ui-surface | #FFFFFF | 编辑区、面板、弹层 |
| --ui-canvas | #F1EEFA | 名片预览背景 |
| --ui-primary | #6750C8 | 主要按钮、选中项 |
| --ui-primary-hover | #5740B8 | hover |
| --ui-primary-soft | #EEE9FC | 选中背景 |
| --ui-text | #24212E | 主要文字 |
| --ui-muted | #696474 | 辅助文字 |
| --ui-border | #DED9E8 | 分隔、输入边框 |
| --ui-focus | #8D77DF | 键盘焦点 |
| --ui-success | #247A57 | 已保存、成功 |
| --ui-danger | #B93850 | 错误 |
| --ui-warning | #916211 | 警告 |

字体：`system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif`；不依赖外网字体。字号：页面标题桌面 28/36、手机 24/32；分区标题 18/26；正文与输入 16/24；标签 14/20；辅助 12/18。数字斜线表示字号/行高。正文不低于 14px，手机输入必须 16px。

间距仅用 4、8、12、16、24、32、40、48。按钮与输入高 44px，移动触摸目标至少 44×44。按钮圆角 10px，面板 16px，卡片由模板自行控制。阴影仅用于浮层和名片预览：`0 12px 40px rgba(50,35,95,.08)`；普通表单不加投影。每块区域最多一层边框，避免套娃。

动效：颜色/透明度 160ms，面板进入 200ms；仅 opacity 与 transform。尊重 reduced-motion。表单保存时不闪动、不改变高度。成功提示用文字与图标，不仅用颜色。

## 4. 统一页面外壳与响应式规则

新建 `src/components/app-shell/`，提供 AppHeader、MobileNavigation、PageContainer、PageHeading。统一导航“制作名片 / Beyond / 我的卡片库”，账户位于右上角；手机账户在顶部头像入口。当前页同时使用文字与底线/填色标识。

| 宽度 | 导航 | 编辑/预览 | 间距 |
|---|---|---|---|
| >=1200px | 顶栏 64px，内容最大 1440px | 左 42%、右 58%，间距 24px；左至少 400px | 左右 32px |
| 768–1199px | 顶栏 64px，紧凑文字导航 | 768–1023 单列+编辑/预览切换；1024–1199 左 400px、右剩余 | 左右 24px |
| <768px | 顶栏 56px+底部 64px 三项导航 | 单列；顶部“编辑 / 预览”切换，默认编辑 | 左右 16px |

断点以 CSS 媒体查询为准。禁止依靠 JS 首屏猜设备，避免 hydration 跳动。最大宽度是容器而非强制视口宽。320px 宽仍能用；所有 grid/flex 子项设置必要的 `min-width:0`；文本可换行，URL 用 overflow-wrap。

桌面主要使用页面滚动，预览可 sticky `top:88px`，不把整页设成固定 100vh 后嵌套多层滚动。只允许模板选择器、聊天记录、弹层内容各自滚动。

手机底栏加 safe-area-inset-bottom；页面底部补足底栏空间。输入框获得焦点、键盘出现时不把分享按钮强行悬在键盘上方；操作条采用正常文档流。全屏对话打开时隐藏主底栏，关闭后恢复滚动与焦点。

## 5. 制作名片首页 /：具体布局与交互

桌面从上到下：
1. 全站顶栏。
2. 紧凑标题行：左“名片工作室”及一句说明，右“已保存到本机 / 保存中 / 保存失败，重试”。
3. 五步导航，保持文字可读。选中紫色底、已完成小勾、未完成灰色；不强制线性完成，点击可切换，不丢字段。
4. 左编辑面板，右淡紫预览面板。预览标题“你的名片”，右上小桌面/手机呈现切换；此切换只改变预览尺寸，不改变名片数据。
5. 分享动作放在预览面板右下角，步骤 05 的字段确认仍在左侧。用同一个 QuickShare 实例，不能两处渲染造成重复发布。

手机：五步导航改为一行当前步骤标题“01 基础信息”加进度“1/5”和“全部步骤”按钮；点击打开步骤底部面板，五个选项可直接跳转。其下“编辑 / 预览”分段控件。切到预览显示名片及底部三个分享动作；编辑第五步底部通过同一响应式容器放分享动作。CSS/组件状态只挂载一个编辑状态与一个发布控制器。

### 5.1 第一步：基础信息

顶部 AI 区：标题“从一句介绍开始。”；3 行文本框示例“我是……，想做一张用于……的名片。”；按钮“帮我整理”；辅助“生成后由你确认”。点击进入配套 AI 流程并带入当前文本；不能把文本立即视作已确认事实。

AI 区下细线分隔，常规表单：展示名称、角色、企业/团队、Logo。桌面标签在上，手机同样在上，避免中英长标签挤压。Logo 88px 方形上传位，存在图片时显示预览以及“更换 / 移除”文字操作；错误在本区域内显示。复用现有加密存储与文件清洗能力，不伪造免解锁上传。企业与角色可空，展示名称为空允许编辑与预览占位，但分享前提示补充。

底部“下一步：联系方式”。AI 区只在第一步完整展开，其余步骤用“AI 帮我调整”文字入口。

### 5.2 第二步：联系方式

保留 ContactPanel 的解锁、保存和敏感信息逻辑。解锁态与未解锁态使用同一浅色面板。提示“保存在本机，是否展示由你决定”。手机号、邮箱等独立行；字段旁不重复“VIP”营销标签。错误定位到字段；保存失败不清空输入。

### 5.3 第三步：其他个人信息

桌面两列、手机一列。爱好、兴趣、才能、证书、院校、Others、社交账号、个人网站使用统一字段组件。院校/证书搜索弹层有无结果态、键盘选择和自定义项。

Others：同一区块内“名称”（最多 120）和“内容”（最多 2000）；预览只显示名称，详细内容点击展开。允许先填名称后填内容；未填内容的名称不作为公开模块出现。社交账号每行“平台 + 账号名称 + 移除”；手机移除放在行末明确位置，不挤成三个小列。新增空行不会在其他输入时消失，修复同步 effect 覆盖临时行的问题。

底部“上一步 / 跳过 / 下一步：挑选模板”，跳过只切步骤，不删除输入。

### 5.4 第四步：挑选模板

左上标题，右上小型“打开效果”选择器。Free、VIP 两个连续分区，每区三张模板缩略图，点击整张即选择；名称、选中标记、必要的 VIP 标签足够。无“查看大图 / 预览此模板 / VIP主题·本地预览”。

桌面每区三列，手机使用两列（第三张位于下一行，不截断）；每组始终三张。More 桌面打开最大 960px 的模态选择器，手机打开全屏选择器，内有筛选和完整模板网格；关闭返回原选择与滚动位置。选择模板立即更新右侧真实名片，选择本身不修改内容。

站点配色不强制用户模板也为紫色。保留所有现有模板 ID 与 legacy 解析。新增 `soft-signal` 免费模板，作为新用户默认：白底、深字、紫色细节、少量右上折纸图形；历史用户继续其已存模板。新模板需同时接入 live renderer 与 PNG 导出，不能只做截图背景。

VIP 能力以现有 entitlement 为准；若没有可靠收费权限实现，不伪造已购买状态或支付入口。允许预览的能力与导出限制在选择时清楚反馈，不等分享才报错。

### 5.5 第五步：选择显示内容与分享

单一列表，逻辑分组“基本身份 / 联系方式 / 个人内容 / 图片”，不做嵌套 tab。每行：开关、名称、一行值摘要、必要的 VIP 标签；分组展开状态不影响选中字段。敏感联系方式默认不选；AI 不能替用户公开。

“跳过”沿用当前显示选择，不是全部勾选；初次无选择则使用非敏感默认值。跳过移动到现有分享动作并提示“沿用当前显示设置”。

分享区只能三按钮。分享名片调用现有发布/原生分享；复制链接创建或复用对应发布快照后复制；下载名片按现有 PNG 行为导出相同公开字段。每个动作分别显示忙碌状态，异常保留名片。若内容自上次确认后变化，点击分享/复制触发精简确认弹层，展示实际公开字段摘要，不增加常驻第四按钮。下载也不能绕过字段选择。

## 9. 最终验收清单
