# Architecture & Privacy v1.3
2026-10-24。以下为待实现设计；密码学和平台兼容性未经验证。

## 1. 结构
Web/PWA → 本地 profile / 加密 vault / 资料确认 / scoped consent / compositor / share projector。
Web 明确授权的最小对话上下文 → 匿名任务 API → LLM、公开研究适配器 → evidence / strategy / sanitized recipe → 本地批准。
明确发布动作 → 独立 publication store（仅投影快照）→ 免注册只读接收页。
B 在研究接口上扩展活动批处理，C 在入口扩展官方 messaging adapter。模板与未来商业权益独立，服务器不保存完整用户资料库。

## 2. 数据边界
| 类别 | 保存位置 | 规则 |
|---|---|---|
| 完整本人资料、private label、私有备注 | 本地 | 不交给研究端；标签/备注不随名片导出 |
| 敏感字段 | 本地加密 vault | 不进入 AI 请求；仅经最终选择导出/发布 |
| 已批准的对话/职业摘要 | 云端短期处理，本地确认结果可保存 | 明示发送内容，不默认携带历史 |
| 公开职业研究与来源 | 研究端临时保存及本地批准结果 | 用户主动指定目标，非私人账户抓取 |
| Strategy / AI Recipe | 研究提案 → 本地 | 无真实敏感字段值，不等于可分享名片 |
| 分享快照 | 本地导出或独立 publication store | 主动发布白名单字段；可转发，不是接收人 E2EE |
| 模板、未来会员权益 | catalog / commerce | 不与身份资料、收件人图谱合库 |

## 3. 授权
CloudContextApproval：该次可见文本/摘要的内容散列、用途、时间；内容改变需重新批准。仅批准传输，不代替 device grant。
ConsentGrant：device/profile、operation、purpose、scope、字段、recipe（适用时）、expiresAt、revokedAt。本地逐次检查。合成默认 15 分钟，可选 5/15/60。
ShareConfirmation：该次白名单输出的 digest、目标动作 file/image/vcard/publish，动作前再次核对；生成新数据对象。分析授权不传递到分享，服务器 jobId 不是本地读取权限。
权限过期只阻止未来访问，不撤回已有草稿、第三方副本或供应商收到的内容。

## 4. 本地加密与恢复
基础非敏感资料无需账户/口令。首次选择持久保存敏感资料时建立口令加密 vault；记录 salt、KDF 参数、算法版本和每次随机 nonce，密钥不明文持久化。采用标准 AES-GCM 和经评审的口令派生方案，参数在 A02 以目标设备测试冻结；不得自制密码算法。
解锁后密钥仅会话内存，默认闲置 15 分钟锁定；重载需重新解锁。锁定会清理敏感编辑缓存，不能宣称安全擦除浏览器全部内存。
加密备份包括带版本的资料与元数据，不包含云端会话/发布管理令牌。校验完整性和口令后原子恢复；失败不覆盖原库。忘记口令无服务器找回；换浏览器需要备份/原浏览器。密码学评审与真机验证是上线门槛。

## 5. 云端会话与发布控制
免注册不等于无授权：服务端生成不可猜测的匿名会话，通过 Secure/HttpOnly/SameSite cookie 识别；状态写操作检查 Origin/CSRF，所有任务逐条校验 owner。
发布后返回独立撤下凭证，仅保留在发布者本地管理存储，不在公共 URL、OG、日志或一般 profile 备份中；凭证丢失不能承诺找回。可单独导出受口令保护的管理备份（A 不必实现）。公共链接只暴露不含姓名/邮箱的随机 publicId。
发布快照不可变；更新需再次确认并创建新版本。撤下旧版本为独立动作。用户清理本地资料不会自动撤下公开副本，界面明确提示。

## 6. 试点运行默认值（工程决策，非外部平台保证）
- 应用侧 AI 对话/研究提案最多保留 24 小时，支持主动删除；清理任务和测试覆盖到期。供应商保留政策必须另外核验。
- 公开快照默认 30 天到期，发布前显示日期，可提前撤下；接收端 Cache-Control: no-store，第三方缓存仍无法保证清除。应用备份的保留/清理需在部署清单明确。
- 单次研究最多 10 个公开来源、5 分钟，有限重试；每匿名会话每小时 10 个研究任务，拒绝时返回 retryAfter。IP 级短期防滥用另行设置，不持久记录可关联用户的完整 IP。
- 纯文本输入上限 20,000 字符，抓取内容上限 2 MiB，A 不接收 PDF；本地图片上限 5 MiB。限制需在 UI/API 一致展示。
这些值可依据成本和设备测试改动，但要同步契约/测试/变更记录。

## 7. 安全屏障
抓取只允许公开 HTTPS，防私网/localhost/保留地址/重定向/DNS rebinding；连接到已验证地址并保持 TLS 主机校验，不能只做字符串检查。限制时间/大小/跳转。
网页为不可信文本，模型不能接触 vault 或工具级任意网络权限。schema、来源引用、本人事实引用、敏感内容和跨人引用验证。
对话本地检测仅辅助；实际发送文本可见，敏感表单值从请求数据路径隔离。媒体重新编码移除 EXIF，用户 SVG A 默认拒绝，富文本不执行脚本。未选字段须在 JSON、图片、vCard、网络与 OG 字节测试中缺席。
无 raw prompts、webhook body、PII、token 日志；只记录状态、成本、耗时和非识别错误码。
本地加密不抵御已解锁页面的 XSS；需 CSP、转义与依赖审查。公开链接可以被转发，UI 不显示“指定接收人安全加密”。
