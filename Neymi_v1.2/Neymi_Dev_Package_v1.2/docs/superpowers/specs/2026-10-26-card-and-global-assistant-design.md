# 基础名片、扩展模块与全局 AI 助手设计

日期：2026-10-26。状态：依据用户接受的产品建议整理；本轮交付文档，尚未实现。

## 产品目标与依据

首次使用者无需注册即可完成一张有联系渠道、有真实内容证明的名片；全局 AI 帮助用户选择针对具体交流最有用的真实信息。沿用 v1.2 的模块化卡片与逐项分享原则，保留 v1.3 的单人准备优先路线。

依据：`legacy/v1.2-baseline/docs/00_PRODUCT_PRD.md`、`legacy/v1.2-baseline/docs/01_USER_JOURNEYS_UX.md`、`legacy/v1.1_full_spec_REFERENCE_ONLY.md`；当前隐私契约继续生效。用户本轮采纳的新产品方向优先于旧文档中冲突的商业范围描述。

## 方案选择

考虑了三种方案：只开放联系方式并锁住所有展示模块；完全开放所有手工模块，仅 AI 和外观收费；保留一个免费内容展示位与一个链接，逐步开放注册和付费权益。

采用第三种方向：新用户能用真实案例体验完整名片，更多功能仍有清楚的升级空间。前两种分别会削弱首次使用价值、或削弱模块权益的差异。实际转化和定价效果尚未经用户试验验证。

## 基础信息与加密

- “创建你的名片”包含：展示名称、公司或团队、角色、联系电话、电子邮件、WeChat、WhatsApp。仅展示名称为制作名片所必需，其余选填。
- 四个联系方式输入框直接可见；已有保险库锁定时显示锁定占位和解锁入口，不把“未解锁”解释为空值，不允许空值覆盖已有密文。
- 新用户填写联系方式时只保留在当前组件内存；保存时设置本地密码并加密。不填写联系方式可直接保存普通名片。取消密码设置不落盘明文。
- 使用现有 Vault、联系方式校验和分享投影，不新增密码或加密系统。表单保存反馈区分基础信息与联系方式是否成功，失败不显示全部保存成功。
- 表单说明固定为：“联系方式加密保存在此浏览器，不会自动上传。分享前，由你选择公开哪些信息。”成功保存后显示“联系方式已加密保存”。
- 联系方式不进入 AI 上下文；写入、预览和对外分享保持独立。公开链接明确说明服务器将保存用户批准公开的快照。
- 不宣称所有个人资料均已加密，也不宣称平台完全不存储个人信息。

## 模块与权益

目标权益：免注册拥有六款模板、基础信息和联系方式、一个网站或社交链接，以及一个 Story 或 Project 展示位。注册后开放更多模块与准备卡管理；付费重点是 AI 额度、批量活动准备、更多定制版本和高级外观。注册额度、付费数量与价格留在独立商业阶段决定。

第一阶段仅实现免费内容编辑和扩展目录预览。没有真实注册/支付功能时，目录明确写“注册功能即将开放”“高级功能即将开放”，禁止展示可用的假注册/假购买按钮。待后续系统验收后再切换为“注册解锁”“升级解锁”。

扩展目录分组：

| 分组 | 模块 |
| --- | --- |
| 业务与证明 | Story、Projects、Services、Portfolio、Skills、合作方式、可接项目时间 |
| 个人表达 | 兴趣、语言、工作风格、自填 MBTI、星座 |
| 外部入口 | 社交账号、个人网站、作品链接、预约链接 |

社交账号按平台、账号和可选 URL 组织，链接按标题和 URL 组织；免费位只允许一条网站或社交记录。MBTI、星座仅由本人选择或填写，不要求完整生日，不作为 AI 判断能力或接收人意愿的依据。

未开放模块以柔和淡色、文字标识和锁图标显示，但必须可点击查看静态示例，保留键盘访问及可读对比度。示例不得写入真实资料或分享投影。

已有用户的额外模块和未知自定义模块继续可读取、编辑、导出；新规则只限制新增，不删除旧资料、不阻断已有准备卡。第一阶段的限制是产品界面规则，不作为已安全实现的商业权益校验。

## 全局 AI

在创建者页面 `/`、`/prepare`、`/activity`、`/cards` 提供共享助手；接收、公开卡片和交接页不自动展示发送者的会话或资料。桌面采用右下入口与侧边面板，手机采用接近全屏面板，避免遮挡主要操作。

三条任务：

1. 为一个人准备：确认接收人、交流目的、用户批准的事实，复用研究与策略流程，交付信息选择建议、依据和名片草稿。
2. 为一场活动准备：名单及业务目标 → 身份确认与证据 → 优先联系对象 → 用户选定对象的介绍策略。沿用现有最多 20 人范围，信息不足时明确说明，不伪造排名或成功率。
3. 一起找亮点：询问经历、服务和案例，提出有依据的亮点候选；用户确认后才存入本人事实。

入口文案每 7 秒轮换一次，三句一轮后收起；打开助手、填写表单、焦点进入气泡、鼠标悬停、页面不可见时暂停。可关闭，同一浏览器会话内不再主动弹出；减少动态效果偏好下显示静态入口。不自动播音、不反复向屏幕阅读器播报轮播内容，不为轮播调用模型。

提示文案：

- 告诉我你要见谁，我帮你挑出最值得展示的信息。
- 给我与会者名单和你的业务，我帮你排出联系优先级。
- 想让对方记住什么？我们一起找到真实、有辨识度的亮点。

路由切换保留当前会话、输入和任务进度，刷新默认清空未保存的对话。每次云端发送显示实际将发送的文字和选中事实，并确认；保持现有逐次发送范围，不自动追加历史聊天。模型未配置时明确不可用，允许继续手工制卡。

AI 结果以建议形式呈现；应用前预览变化并确认。发卡仍需独立选择字段和确认。普通路由切换不丢草稿；发生资料版本变更时要求重新核对，不把旧建议直接覆盖到新资料。

## 验收与阶段边界

第一阶段可交付免费完整名片及扩展目录；第二阶段可交付全局助手与三个实际任务闭环；第三阶段单独建设账号、支付、服务端额度和权益恢复。

核心验收：无注册基础卡完成；密码取消/锁定/保存失败均不丢旧数据；未选联系字段在 JSON、vCard、PNG 和公开投影中均不存在；危险 URL 不可打开；MBTI 不参与职业匹配推断；切换路由不丢助手输入；浮窗可关闭且不遮挡移动端操作；缺服务配置不假报成功。

发布前区分受控接口测试和真实服务验收。真实 LLM/搜索、真机、支付与账号能力都不能通过仅有 UI 或模拟测试声称完成。
