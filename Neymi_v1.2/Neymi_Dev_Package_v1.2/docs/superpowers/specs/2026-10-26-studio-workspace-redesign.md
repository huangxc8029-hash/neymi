# 名片工作室页面重设计

## 意图与用户

让第一次来的访客看懂 Neymi 能做什么，并能从制作名片自然走到核对分享内容；让回访用户能直接进入编辑、准备卡管理或收到的名片。访客无需注册即可制作、保存、查看和回赠基础名片。

## 目标与边界

- 以名片制作和分享为首页主流程；AI 单人准备、活动准备、已准备卡和收件入口构成清晰的次级导航。
- 保留本地资料、联系方式加密保存、云端上下文审批和最终分享单独确认的既有隐私边界。
- 电脑端采用导航、编辑区、实时预览三栏工作室；手机端采用主要任务导航、专注编辑、独立预览与固定主操作。
- 分享确认展示可读的名片预览和选中字段，不用原始 JSON 代替最终效果；保留文件导出、公开链接的当前能力和风险说明。
- 仅调整登录入口的响应式呈现；真实登录、账号同步、支付和会员权益不在此实现。
- 反目标：注册墙、上传完整本地资料、自动公开联系方式、隐式追踪、需要登录才可接收或回赠。

## 方案与选择

1. 精品名片工作室：编辑、实时预览和分享形成连续流程。推荐，最符合免注册制作及逐字段审批的现有产品事实。
2. 名片夹首页：突出已创建和收到的卡，适合回访，首次创建引导较弱。
3. AI 助理首页：从对话开始，展示差异化明显，但基础名片会被较重流程掩盖。

选择方案 1，并加入方案 2 的直接管理入口；AI 保持任务型次级入口。

## 实现方向

- 首页首屏提供产品说明、可交互示例和「免费制作名片」入口；已有资料时优先展示用户的卡片与编辑/分享动作。
- 编辑组织为内容、外观、分享三个阶段；逐步展开高级内容，避免初始表单暴露全部模块选项。
- 桌面三栏在窄视口收拢为移动任务导航和分步编辑；预览独立呈现，编辑状态不丢失。
- 成功状态给出明确的继续编辑、复制链接或管理名片动作；失败状态保留输入并说明恢复方式。
- 使用现有深色、暖金与卡片模板作为视觉依据，减少无目的装饰，增强内容层级、留白及焦点状态。

## 约束与验收

- 沿用现有 Next.js/React、样式系统和数据契约；不替换真实产品文案所表达的功能事实。
- 适配 360/390 手机、768 平板和 1440 桌面宽度，键盘可操作、焦点清晰、支持减少动态效果。
- 分享预览应能对应最终投影字段；联系方式默认不选；公开链接仍明确提示可转发。
- 登录页面不可暗示本地资料已自动同步；没有已实现的认证服务时不得添加看似可用的真实登录表单。
