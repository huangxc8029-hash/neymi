## 正式试用前必须落实的外部事项
1. 模型和搜索提供商、密钥、费用上限、数据地区与供应商留存策略（A12）。
2. HTTPS 托管地址、数据库、发布清理与备份保留操作；不能假设已部署（A10/A12）。
3. 本地密码学参数和实际手机耗时、备份可恢复性（A02/A12）。
4. 真机和自愿试用者反馈，关键事实人工评测记录（A12）。
5. B 开始前定活动文件解析、安全与排名基准；C 开始前定官方渠道准入。
6. AI 付费价格/额度、付费恢复、视觉产品定价另立需求；不阻塞 A。

缺配置时使用接口和显式 fixtures，可继续不依赖它们的工作；真实联调标 BLOCKED。新增范围必须写变更 ID、契约、任务与验收，不静默扩大。

## 提供商决策补充（2026-10-25）
- 用户选择 DeepSeek 作为 AI 服务、Tavily 作为公开搜索服务。适配器只读 `NEYMI_DEEPSEEK_API_KEY` / `NEYMI_DEEPSEEK_MODEL` 和 `NEYMI_TAVILY_API_KEY`；缺少密钥时明确报告未配置。密钥只放在服务端环境，不放在浏览器或仓库。
- 单次请求仍只包含用户明确批准的当前文本/上下文，不附带历史对话或本地保险库联系方式。开始真实试点前需核验 DeepSeek 与 Tavily 对应账户的费用、数据地区和保留政策。

## B 实施补充（2026-10-25）
- 活动 PDF 使用 Mozilla PDF.js 在浏览器本地提取文本，限制 10 MiB / 60 页 / 20,000 字；不处理扫描件，不执行 PDF 脚本。实现范围不等同 OCR 或安全审计结论。
- 活动 URL 通过现有 SSRF 安全抓取器临时读取 HTML/纯文本；抓取结果只返回浏览器，不写入服务器任务存储。显式 AI 授权后，单人嘉宾简介与选定本人上下文会在本次请求中发送给模型服务，必须另行核验供应商留存政策。
- B 的离线主题排序使用文字线索和用户标记，不是心理偏好、关系成功概率或经独立核验的匹配结论。未配置模型时，方案服务沿用 A 的规则后备路径并生成低置信度草案。

## C 实施补充（2026-10-25）
- 依据 C harness 的要求，当前仅提供 provider-neutral seam 和明确启用的 `fixture-hmac` 模拟适配器；官方消息渠道、入驻资格、费用、密钥管理、数据区域/留存政策均未获确认，生产 webhook 默认返回未配置，不得视为实时接入。
- Webhook 仅解析签名覆盖的原始请求；模拟协议仅允许不透明事件 ID 和白名单事件类型。SQLite 仅保存事件 ID/过期时间用于 7 天幂等，不保存 webhook 正文。每个 fixture channel 的速率限制为进程内每分钟 60 个有效事件；生产前需使用所选平台身份键与共享限流/存储。
- 交接 ticket 仅关联现有公开快照，5 分钟内单次消费；数据库只保存 ticket 哈希。fragment 不随浏览器请求发送，消费 API 要求同源 POST。公开快照仍可转发，ticket 不提供私密访问或 E2EE，也不会读取设备 vault。
- 自动发消息和 provider 重试未实现；本阶段不做自动外联。平台选定后，必须按官方 webhook 规范实现签名映射、限流、有限重试与真机 WebView 联调，且须先通过 G-A3/G-B 外部门槛。
