## 高风险与责任闸门
| 风险 | 控制 | 验收 |
|---|---|---|
| 用户误以为所有内容不上云 | 对话显示实际输入；公开快照另行发布 | A05,A10 |
| 对话意外包含敏感信息 | 本地检测/替换、独立表单、实际发送预览；不承诺识别全部 | A06 |
| 加密密钥/口令恢复薄弱 | 标准算法、锁定、篡改/口令测试、人工密码学审查 | A02,A12 |
| 错人/假引用/虚构本人事实 | 消歧、引用关系、用户事实确认、语义抽查 | A07,A08,A12 |
| 未选字段泄露 | 新对象白名单投影，字节/网络/OG 检查 | A04,A10 |
| 公开链接被转发/缓存 | 公开提示、默认通用封面、到期/撤下不保证撤回 | A10 |
| 失去撤下凭证 | 本地管理记录、30d 默认到期，删除本地前提示 | A10,A11 |
| 浏览器隔离/清理存储 | 加密备份恢复，原浏览器路径，空间不足失败保护 | A02,A11 |
| 匿名服务被滥用 | owner/CSRF/配额/预算，避免全量日志 | A05 |
| SSRF/网页注入/XSS | 地址与跳转验证、内容隔离、输出转义、媒体净化 | A04,A07 |
| 多次对话变相上传整库 | 按次选择最小摘要，不携带全部历史，UI 清晰 | A05,A06 |

## 正式试用前必须落实的外部事项
1. 模型和搜索提供商、密钥、费用上限、数据地区与供应商留存策略（A12）。
2. HTTPS 托管地址、数据库、发布清理与备份保留操作；不能假设已部署（A10/A12）。
3. 本地密码学参数和实际手机耗时、备份可恢复性（A02/A12）。
4. 真机和自愿试用者反馈，关键事实人工评测记录（A12）。
5. B 开始前定活动文件解析、安全与排名基准；C 开始前定官方渠道准入。
6. AI 付费价格/额度、付费恢复、视觉产品定价另立需求；不阻塞 A。

缺配置时使用接口和显式 fixtures，可继续不依赖它们的工作；真实联调标 BLOCKED。新增范围必须写变更 ID、契约、任务与验收，不静默扩大。
